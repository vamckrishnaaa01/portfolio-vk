# Vamsi Krishna — Portfolio

Premium dark/editorial portfolio for Vamsi Krishna.

## Features
- Responsive one-page portfolio with cinematic luxury styling
- Personal hero photo
- TAP Academy learner section with external link
- Visual skill cards
- Student Management System, ML/GA project and Online Payment System
- Publication, education, certifications and coding profile details
- Resume download
- LinkedIn / GitHub / email / phone links
- Feedback/contact form wired to FormSubmit
